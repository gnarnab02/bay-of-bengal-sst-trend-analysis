# bay-of-bengal-sst-trend-analysis

This repository contains the R scripts and supporting materials
used for the analysis presented in:

Two Decades of Sea Surface 
Temperature Trends in the Bay of 
Bengal (2004–2024) from Multi
Satellite Observations (NOAA, 
NASA, Copernicus)

## Study

This study investigates sea surface temperature variability
and trends in the Bay of Bengal using satellite and
in-situ/reanalysis observations.

## Data

The analysis uses:

- MODIS SST
- NOAA OISST
- Copernicus Marine Service data

## Methods

- Data preprocessing
- Spatial analysis
- Temporal analysis
- SST trend estimation
- Satellite–in-situ validation
- Statistical analysis
- Visualization

## Repository Structure

- `R/` — R analysis scripts
- `figures/` — selected figures
